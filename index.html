About this dashboard: data, metrics and method
Business question
Are we hitting revenue targets, and which regions, channels and product lines drive revenue and profit?
Data
~13,500 synthetic order lines and a monthly target plan for a B2B industrial distributor. Created for this portfolio; not company data.
Target attainment
Revenue ÷ planned revenue target for the same period.
Gross margin
(Revenue − cost of goods) ÷ revenue, after discounts.
Average order value
Revenue ÷ number of orders.
Comparison
Headline figures compare Aug–Oct 2026 with May–Jul 2026.
Method
Python (pandas) to clean and aggregate; KPI logic mirrors SQL group-bys; visualized with D3.

Recommended actions from this view: protect Safety Equipment and Tools & Hardware (highest margin) in promotions, review discounting on Packaging, and set a recovery plan for the spring dip using Q1 pipeline coverage.

Portfolio project built with Python (pandas) and D3.js · All data is synthetic. Source code and data are in this repository.
